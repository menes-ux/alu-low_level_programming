# alu-low_level_programming

C programming projects. Each project has its own source files and README.

| Directory | Topic |
| --- | --- |
| `hello_world` | Compilation stages, basic output, and C data type sizes. |
| `variables_if_else_while` | Variables, conditions, loops, and character output. |
| `functions_nested_loops` | Functions, prototypes, character checks, and nested loops. |
| `pointers_arrays_strings` | Pointers, arrays, and basic string operations. |
| `recursion` | Recursive string operations, factorials, powers, square roots, and prime checks. |
| `malloc_free` | Dynamic allocation of arrays, strings, and grids. |
| `structures_typedef` | Structures, type definitions, and memory management. |
| `function_pointers` | Callbacks, array iteration, and a simple calculator. |
| `file_io` | Reading, creating, appending to, and copying files. |
